**AI agents · developer tooling · backend engineering**

I build tools that help AI assistants work with real codebases, and backend systems that keep those tools useful and reliable. I'm based at Beijing University of Chemical Technology.

### Selected work

- **[GitLab Code Reader MCP](https://github.com/nanami7777777/gitlab-code-reader-mcp)** — A Go MCP server with nine focused tools for exploring remote GitLab repositories. It supports file and symbol reading, code search, diffs, blame, and commit history, with output designed to conserve context.
- **[ContextFix](https://github.com/nanami7777777/Context-Aware-Fixer)** — A TypeScript CLI that gathers repository context, analyzes bugs with an LLM, and produces reviewable patches. It uses dependency information, stack traces, and Git history to find relevant code.
- **[MistAI](https://github.com/nanami7777777/MistAI)** — A Go desktop AI assistant with streaming chat, multiple conversations, translation history, and MongoDB persistence.
